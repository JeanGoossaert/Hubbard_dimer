# Hubbard_dimer
This repository contains python scripts that calculate exact and approximate energy levels in the asymmetric Hubbard dimer model.
Are included:

- Exact Kohn-Sham (DFT)
- Restricted and Unrestricted Hartree-Fock
- One-shot $GW$ correction within RPA ($G_0W_0$) and with the exact screened potential ($G_0W$)
- Vertex correction beyond $GW$ ($G_0\tilde W$)
